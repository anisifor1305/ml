# Практика 12: проверка данных до обучения

## Задача и время

Предсказываем возврат заказа за 30 дней после placed_at.
Одна строка результата — заказ. Прогноз делаем в prediction_at.
Время всех файлов — UTC без явного часового пояса; сравнивается в одной шкале.
Выгрузка получена 20 ноября 2026 в 12:00 UTC — это учебный сценарий,
а не текущая дата. Это значение SNAPSHOT в скрипте.

Данные синтетические, фиксированные. Данные не надо скачивать:
exercises/data/lesson_12/. Исходные файлы не перезаписывать.

## Источники

orders_dirty.csv:
- row_id — уникальный ID строки выгрузки, НЕ заказа;
- order_id — ID заказа; возможны повторы загрузки и версии одного заказа;
- customer_id — ID клиента;
- placed_at — время оформления; prediction_at — момент прогноза;
- available_at — когда данная версия заказа стала доступна системе;
- amount — стоимость заказа в рублях;
- channel — канал оформления;
- returned_30d — цель: 1, если был возврат за 30 дней, 0, если не было;
  для ещё не завершившихся окон возможен пропуск;
- lifetime_spend_at_extract — сумма трат клиента на дату выгрузки;
  включает покупки после момента прогноза, не использовать как признак.

receipts.csv: одна авторитетная квитанция на order_id; amount в рублях,
available_at — время доступности квитанции.

contacts.csv: одна строка на обращение, contact_id уникален.
order_id связывает обращение с заказом; event_at — время события;
available_at — время поступления записи в систему.

## Контракт данных и правила исправления

1. Для каждого заказа бери последнюю версию, доступную к prediction_at.
   Если таких версий нет, заказ исключается. Для повторов одной версии
   оставь строку с наименьшим row_id. Порядок выбора при равенстве времени:
   available_at по убыванию, row_id по возрастанию.
2. Заказы без customer_id исключаются из этой учебной задачи.
3. Допустимые каналы: app и web. Разрешено убрать крайние пробелы и привести
   регистр. Неизвестные категории не угадывать: такие заказы исключаются.
4. amount должен быть конечным и неотрицательным. Неверные/отсутствующие суммы
   восстанови из квитанции, только если она доступна к prediction_at.
   Если восстановить невозможно, исключи заказ. Проверяй уникальность квитанций
   перед объединением. В этом наборе квитанции уникальны.
5. Большая, но корректная и подтверждённая сумма остаётся. За усами boxplot
   могут находиться реальные покупки.
6. Не заполняй цель нулём. Не меняй row_id, даты, ID или другие исходные поля.

Программа проверяет контракт, а не «единственный правильный стиль кода».

## Новые инструменты: сначала разбери микро-примеры

У pandas nunique(dropna=True) считает разные непустые значения:
Series([1, 1, None]).nunique() → 1. Без аргументов пропуски исключаются.

np.isfinite проверяет число: np.isfinite([10, np.inf, np.nan]) →
[True, False, False]. Бесконечность не обнаруживается обычным isna.

Строковый аксессор .str позволяет применить операцию ко всему текстовому столбцу.
.str.strip() удаляет пробелы на краях, .str.lower() переводит буквы в нижний регистр:
Series([" Web "]).str.strip().str.lower() → Series(["web"]).

duplicated(subset=[...], keep=False) помечает ВСЕ строки с повторяющимся ключом.
drop_duplicates(subset=[...], keep="first") оставляет первую строку на ключ:
DataFrame({"id":[1,1,2], "x":[10,20,30]}).drop_duplicates("id") →
строки (1,10), (2,30). Сначала сортируй по нужному приоритету!

sort_values(by, ascending) сортирует по столбцам; для разных направлений передай
список флагов: sort_values(["id","x"], ascending=[True,False]) —
ID по возрастанию, внутри ID значение x по убыванию.
После отбора reset_index(drop=True) создаёт новый числовой индекс,
не добавляя старый индекс в столбцы.

pd.Timedelta(days=30) — интервал в 30 суток. Например,
Timestamp("2026-01-01") + Timedelta(days=30) → Timestamp("2026-01-31").

Подсчёт/объединение групп и сравнение дат используют знакомые groupby, merge
и булевы маски. При merge validate="m:1" проверяет уникальность ключа справа.

сама меняет состав сравниваемых данных. Внешней генеральной совокупности здесь
нет, поэтому смещение отбора обсуждается как риск, а не установленный факт.
