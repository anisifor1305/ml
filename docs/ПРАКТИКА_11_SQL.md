# Занятие 11: агрегаты, окна и WITH

Условия и TODO: `exercises/sql/lesson_11/01.sql` … `08.sql`.
Пиши по одному запросу в каждом файле. Python используется только для проверки.

Используется учебная база занятия 10. Если сервер остановлен, запусти из корня проекта:

```bash
.venv/bin/python scripts/lesson10_db.py start
```

Проверить первое задание:

```bash
.venv/bin/python exercises/lesson_11.py --task 1
```

Без `--task` скрипт проверяет все восемь файлов по порядку. Для Docker добавь
`--backend docker` к обеим командам. Проверяются названия столбцов, число,
порядок и значения строк, включая NULL. Выбор SQL-конструкций проверяется при разборе.

Начни с 01: один клиент — одна строка. У Ады 3 заказа на общую сумму 500.
В конце объясни, почему №03 сохраняет строки заказов, почему первый заказ
в №04 получает NULL и почему №08 возвращает ровно одну строку на клиента.
