Все задачи этапа перечислены здесь; скрытых дополнительных подзаданий нет.
Рабочий файл: exercises/e02_service.py. Решение обработчика пишешь сам.

## Модель

cointegrated/rubert-tiny-sentiment-balanced: классификация коротких русских текстов,
категории negative / neutral / positive. Это готовая обученная модель.
Имя и точная версия зафиксированы в src/mldata/e02_model.py.
Работа локально на CPU. GPU, аккаунт Hugging Face и платный API не нужны.
Оценка score не является гарантированной вероятностью правильности предсказания.

Загрузчик подготовлен отдельно, чтобы не требовать от ученика знания внутреннего
устройства Transformers. Зависимости: requirements-e02-model.txt.

## Инструменты

Импорт загрузчика: `from mldata.e02_model import load_classifier`.
`classifier = load_classifier()` создаёт объект для классификации: загружает
токенизатор (преобразование текста в числа) и веса модели.
Вызывай его ОДИН раз на уровне модуля перед запуском сервера, вне обработчиков.
При первом запуске файлы скачиваются; следующие используют локальный кэш.
Текст при таком запуске обрабатывается на компьютере, не отправляется в облачное API.

Вызов объекта: `classifier(text, truncation=True, max_length=512)`.
text — строка; truncation=True разрешает обрезать слишком длинную последовательность;
max_length=512 ограничивает количество токенов (частей текста, не символов).
Наше ограничение 500 символов в TextRequest остаётся отдельной проверкой входа.

Результат одного текста — список с одним словарём, например:
`[{'label': 'positive', 'score': 0.97}]`.
Первый словарь доступен по индексу 0; это не словарь верхнего уровня.
Цифры приведены для иллюстрации формы, точное значение не ожидается.

Pydantic Field: ge=0 — >=0; le=1 — <=1.
Ограничение строковых вариантов: импорт `Literal` из typing.
Например, `color: Literal['red', 'blue']` допускает только эти две строки.

## Сделать

1. Импортировать загрузчик и один раз создать classifier вне функций обработчиков.
2. Создать PredictResponse: label допускает только negative/neutral/positive;
   score — float от 0 до 1 включительно.
3. Добавить POST /predict с response_model=PredictResponse.
4. Принимать существующий TextRequest, передавать request.text в classifier.
5. Возвращать первый словарь результата модели, без заглушек и ручных правил.
6. Сохранить /health и /inspect.
7. Проверить три разных текста через /docs и один ошибочный запрос с пустой строкой.
