# ML learning track

Учебный репозиторий для практики по ML / AI Research Track.

## Запуск

```bash
source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q
```

## Структура

- `scripts/` — исполняемый код;
- `tests/` — автоматические тесты;
- `src/` — переиспользуемый код;
- `notebooks/` — исследовательские ноутбуки;
- `configs/` — конфигурации будущих экспериментов;
- `data/` — локальные данные; реальные данные не попадают в Git.
